# SmartSpend — 지능형 개인 재무 관리

현대/국민/롯데 카드 이용내역 기반 지출 분석·예측 대시보드 (Next.js + ECharts)

## 기능
- **카테고리 분류**: 가맹점 키워드 기반 자동 분류 (식비/교통/주거·통신/쇼핑/의료/교육·문화/공공·레저/금융·페이/기타)
- **지출 추이 분석**: 카테고리별 파이 차트, 월별 막대/라인 차트, 소비 인사이트
- **예측**: 이동평균 + 선형추세 결합으로 다음 달 지출 예측
- **필터**: 카드사(현대/국민/롯데), 기간(전체/6개월/12개월/연도)

## 데이터
- `data/expenses.json` — 카드사별 이용내역 (날짜/카드/가맹점/금액)
- 갱신: `python parse_all.py` (Downloads/카드 폴더 → JSON)

## 실행
```bash
npm install
npm run dev
```
